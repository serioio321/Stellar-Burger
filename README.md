# Проектная работа: Stellar Burger

Интерактивное веб-приложение для сборки и заказа космических бургеров. Разработано с использованием современного фронтенд-стека, включая React, Redux Toolkit и TypeScript. Проект демонстрирует навыки работы с роутингом, асинхронными запросами, управлением глобальным состоянием и компонентным подходом.

## Описание

**Stellar Burger** — платформа, позволяющая пользователям собирать бургеры из набора космических ингредиентов, оформлять заказы и отслеживать статус заказов в реальном времени. Приложение реализует авторизацию, защищённые маршруты и интеграцию с API.

---

## Стек технологий

- **React** — библиотека для создания пользовательских интерфейсов
- **TypeScript** — типизированный JavaScript
- **Redux Toolkit** — управление состоянием приложения
- **Webpack** — сборщик модулей
